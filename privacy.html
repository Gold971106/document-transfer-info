작성일: 2026-09-28 · 적용 대상: bunshin의 개인용 Google Drive 문서 전달 기능 및 이 안내 사이트

bunshin은 운영자 본인의 업무 문서·EPUB 파일을 Google Drive에 업로드하고 공유 링크를 안내하는 개인용 도구입니다. 일반 대중을 대상으로 계정 연동 서비스를 제공하지 않습니다.

1. 접근하거나 처리하는 정보

  • 전달 대상 파일: 사용자가 업로드를 요청한 문서·EPUB·ZIP 파일과 파일명·형식·크기.
  • Drive 작업 정보: 업로드한 파일의 식별자, 이름, 크기, 공유 링크 및 공유 권한.
  • 인증정보: Google OAuth 액세스 토큰, 갱신용 토큰 및 API 연결에 필요한 설정. Google 계정 비밀번호를 앱에 입력하거나 저장하지 않습니다.
  • 작업 기록: 처리 결과, 파일 경로, 공유 링크, 오류 메시지 등 업무 자동화에 필요한 기록.
  • 문의 내용: 문의 이메일을 보낸 경우 발신 주소와 문의 내용.

현재 요청하는 Google Drive 권한은 기존 Drive 파일에도 접근할 수 있는 범위입니다. 앱은 승인된 권한을 사용자가 요청한 문서 전달 작업에 사용합니다.

2. 정보를 사용하는 목적

파일 업로드, 업로드 결과와 공유 권한 확인, 공유 링크 전달, 인증 유지 및 오류 확인에 사용합니다. Google API로 받은 정보를 광고 타게팅, 데이터 판매 또는 범용 인공지능 모델 학습 목적으로 사용하지 않습니다.

3. 데이터 전달과 외부 서비스

  • Google: 파일은 승인한 계정의 Google Drive에 저장됩니다. 인증 요청과 API 작업에 필요한 정보가 Google에 전달됩니다.
  • 파일 수신자: 전달용 파일은 링크를 가진 누구나 열람하도록 공유될 수 있습니다. 해당 링크를 받은 사람은 파일에 접근할 수 있으므로 민감한 파일은 공유 전에 확인해야 합니다.
  • 업무비서 실행환경: 파일명, 처리 결과, 오류 및 공유 링크 등은 연결된 업무비서의 도구 출력·대화 기록에서 처리될 수 있습니다. Google 인증 토큰과 비밀번호를 안내 사이트나 공개 저장소에 게시하지 않습니다.
  • GitHub Pages: 이 안내 사이트의 호스팅에 사용합니다. 페이지에는 별도의 분석 스크립트, 로그인 양식 또는 파일 업로드 양식을 두지 않습니다. 호스팅 제공자는 사이트 제공·보안을 위해 접속 정보를 처리할 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다.

4. 저장과 보관

OAuth 인증정보는 운영자가 관리하는 실행환경에 저장하며 인증 갱신과 API 호출에 사용합니다. 인증정보는 재인증으로 교체하거나 운영자가 삭제할 때까지 남을 수 있습니다. 원본·작업 파일과 작업 기록은 해당 실행환경에 저장될 수 있으며, 운영자가 업무상 필요에 따라 정리합니다.

Google Drive에 업로드한 파일은 사용자가 삭제할 때까지 해당 계정에 남습니다. Google 연결을 해제하더라도 이미 업로드된 파일, 기존 공유 권한 및 로컬 작업 기록이 자동으로 삭제되는 것은 아닙니다.

5. 접근 철회와 삭제

  • Google 계정의 서드 파티 연결 관리에서 bunshin의 접근 권한을 철회할 수 있습니다.
  • 업로드한 파일은 Google Drive에서 직접 삭제하고, 공유 설정에서 링크 접근을 제한하거나 해제할 수 있습니다.
  • 실행환경에 남은 인증정보·파일·작업 기록의 삭제는 운영자가 해당 저장 위치에서 별도로 처리해야 합니다.
  • 개인정보 확인·삭제 및 관련 문의는 아래 이메일로 요청할 수 있습니다. 법령상 보관 의무가 있는 경우 해당 범위에서 처리합니다.
